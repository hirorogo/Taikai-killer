# toy-ts-temporal（TypeScript・日付の差日数）

`src/main.ts` に **named export** で関数を実装せよ。`default export` は禁止。

```ts
export function daysBetween(a: string, b: string): number
```

## 仕様

2つの日付文字列 `a`, `b`（いずれも `YYYY-MM-DD` 形式のグレゴリオ暦の日付）を受け取り、
その間の**差日数**を返す。

- 返り値は **絶対値**（非負整数）。順序非依存：`daysBetween(a, b) === daysBetween(b, a)`。
- 同じ日付なら `0`。
- 隣接日（例 `2021-01-01` と `2021-01-02`）は `1`。
- うるう年・月跨ぎ・年跨ぎを正しく扱う（例 `2020-02-28` → `2020-02-29` は `1` 日、`2020-02-28` → `2020-03-01` は `2` 日）。
- うるう年判定はグレゴリオ暦（4で割り切れ、かつ「100で割り切れるなら400でも割り切れる」年がうるう年）。
  - `2000` はうるう年（2/29 が存在）。`1900` はうるう年でない（2/29 は不正日）。
- **不正形式は `throw`** する（`Error` を送出）。以下はすべて不正：
  - フォーマット不一致：`""`、`"2021-1-1"`（ゼロ詰めなし）、`"2021/01/01"`、`"2021-01-01 "`（末尾空白）、`" 2021-01-01"`、`"2021-13-01"`、`"abcd-ef-gh"`、`"20210101"`、`"2021-01-01T00:00:00"`。
  - 範囲外の月：`month < 1` または `month > 12`（例 `"2021-00-10"`, `"2021-13-01"`）。
  - 範囲外の日：`day < 1` または当該月の日数を超える（例 `"2021-01-00"`, `"2021-01-32"`, `"2021-04-31"`（4月は30日まで）, `"2021-02-29"`（2021 は平年なので 2/29 は不正）, `"1900-02-29"`（1900 は平年））。
  - 文字列以外の型が来た場合も `throw`（実装は文字列前提でよいが、非文字列でも安全に弾く）。

## 注意（実装ヒント）

- `Date` のパースは環境差・ロールオーバー（`new Date("2021-02-29")` が 3/1 になる等）があるため、
  **自前でフォーマット検証 + 日数計算**するのが安全。`new Date` のローカルタイムゾーン依存にも注意（UTC で計算する）。
- 厳密な正規表現 `^\d{4}-\d{2}-\d{2}$` でまず形を弾き、年月日を整数化してから範囲・実在チェックを行う。

## 例

```ts
daysBetween("2021-01-01", "2021-01-01") === 0
daysBetween("2021-01-01", "2021-01-02") === 1
daysBetween("2021-01-02", "2021-01-01") === 1   // 順序非依存
daysBetween("2020-02-28", "2020-02-29") === 1   // うるう日
daysBetween("2020-02-28", "2020-03-01") === 2   // うるう年の月跨ぎ
daysBetween("2019-02-28", "2019-03-01") === 1   // 平年の月跨ぎ
daysBetween("2020-12-31", "2021-01-01") === 1   // 年跨ぎ
daysBetween("2000-01-01", "2000-12-31") === 365 // 2000 はうるう年（366日年 → 1/1 から 12/31 は 365）
daysBetween("1999-01-01", "1999-12-31") === 364 // 平年
daysBetween("2021-02-29", "2021-03-01")         // throw（2021 は平年）
daysBetween("2021-13-01", "2021-01-01")         // throw（月範囲外）
daysBetween("2021-1-1",  "2021-01-01")          // throw（ゼロ詰めなし）
```
